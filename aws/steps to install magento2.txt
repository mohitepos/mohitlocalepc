steps to install magento2 



Step 1:- (install ubuntu setup as this video)
https://www.youtube.com/watch?v=osqZnijkhtE



Step 2: Add the Ondrej PPA for PHP 8.1
1.Add the Ondrej PHP PPA repository:
sudo add-apt-repository ppa:ondrej/php -y
2.Update the package list again:
sudo apt update -y



Step 3: Install PHP 8.1 and Required Extensions
sudo apt install -y php8.1 php8.1-cli php8.1-fpm php8.1-mysql php8.1-bcmath php8.1-gd php8.1-intl php8.1-mbstring php8.1-mysqlnd php8.1-pdo php8.1-soap php8.1-xml php8.1-zip


Check php version 
php -v


Step 1: Install Apache
sudo apt update
sudo apt install apache2 -y


Step 2: Start Apache Service

sudo systemctl start apache2
sudo systemctl enable apache2







Switch php version 

sudo update-alternatives --config php
sudo systemctl restart apache2    # If you're using Apache
